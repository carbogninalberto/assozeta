# Assozeta

Assozeta is an open-source management interface for sports associations, built with Svelte and Vite.

The frontend application is in [`UI/`](UI/). See [`UI/README.md`](UI/README.md) for development and production build instructions.

The frontend expects a compatible backend API at `/api`. Backend implementation and deployment are managed separately from this repository.
